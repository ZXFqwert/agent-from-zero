# 第 1 课：从消息到一次模型调用

## 本课目标

理解模型调用的输入是消息历史；接下来接通一次真实模型请求。本课完成后仍只是聊天程序，工具和执行循环要在后续加入。

## 现在先做这个小练习

在项目根目录新建 `hello_agent.py`，用你会的列表和字典表达三条消息：

1. system：你是一个耐心的 Python 助教。
2. user：什么是 Python 列表？
3. assistant：列表是按顺序存放多个元素的容器。

每条消息用 `role` 和 `content` 两个字段，整个列表命名为 `messages`。用 `for` 循环打印每条消息的角色和内容。

```powershell
python hello_agent.py
```

预期：打印三条带角色的消息。此练习不会连接模型；assistant 内容是手写的示例。

做完后把代码或输出给助教看，并试着回答：如果用户继续问“怎么往里面加元素？”，应该把什么追加到列表？

## 下一小步：接通模型

先明确服务提供方、模型名称和接口地址。API Key 只在本机输入，不写入源码或学习记录。

接通后观察请求消息与模型响应的差别，并处理缺少配置和接口失败。具体 SDK 和响应字段根据选定服务的官方文档确定。

## 本课验收

- [ ] 能解释 system、user、assistant 的用途。
- [ ] 能追加下一轮用户消息。
- [ ] 成功发起一次真实模型调用。
- [ ] 能指出哪部分是自己编写的程序，哪部分是模型返回的内容。

前三条手写消息只是练习结果，不算真实模型调用成功。
