# 第四章验收 · 遗忘回廊

日期：2026-10-03。版本 0.5.0 / season-0.5.0 / 新内核 5；旧内核 1–4 保持冻结。

## 实现与实际路线

八个作者任务有 17 条参考/恢复/替代路线。容量与摘要影响装置输入；档案不是当前上下文，场景动画不能决定胜负。普通资料每次读取一枚晶石，操作/验收一枚；装卷/摘要不扣资源。文档容量按明确的教学格数，独立工作栏仅保留最新一条收到的工具结果。

| 任务 | 实际界面验收 |
| --- | --- |
| 折叠的地图 | 空卷操作失败且世界不变；读取地图仍未入上下文，伙伴停止；装卷后开门、独立验收。 |
| 窄小的卷轴袋 | 完整地图占满三格，口令卡超容量被拒；只留路线的摘要缺潮次而执行失败；补回潮次的摘要与口令一起通关。 |
| 消失的页边 | 四格原药方不能直接携带；只留剂量导致失败；两格摘要保留剂量、过敏与批次，随后执行及验收。 |
| 索引里的夜班 | 用“夜班”把索引筛为唯一命中；读取、装卷后由伙伴决定操作与验收。没有把搜索命中当作自动取得知识。 |
| 千面档案官 | 三格同时携带口令摘要与通桥规则；首次抄写后口令转铜、旧封印失效；原样抄写实际被拒；移出银口令，重新读取、压缩、装入铜口令后恢复封印及通桥。 |
| 陌生的野战药棚 | 独立选择名册与照护单；坏摘要只留姓名失败，保留姓名和病区后成功。无提示时记录此次独立迁移。 |
| 传闻的捷径 | 按旧报走北路真的折返，验收仍失败；移出旧报、读取和携带当前实测后从南路通过。 |
| 回执抽屉 | 发凭证后独立验收替换旧工作回响，核销缺输入而失败；从已发生的登记取回凭证再核销，发凭证副作用仅一次。也有直接在替换前核销的合法替代解。 |

制作方使用拥有的 Chromium 会话，在 390×844 实际点击这些控件；前三章用原先真实导出 24 关存档，通过正常文件选择导入。没有通过注入隐藏状态伪造解锁或胜利。

## 软件与存档

156 项前端测试、TypeScript、内容校验与正式构建通过。内容发布门执行全站 61 条路线，核对 32 任务、32 份剧情、7 档案与 16 Phaser 纹理。新增负例包括档案事实不入上下文、缺输入不泄露正确值、超容量原子拒绝、摘要不创造事实、展开溢出、旧快照不自动更新、策略不读取秘密世界、工作回响替换与篡改存档拒绝。
