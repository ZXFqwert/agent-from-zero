## 制作方 App / 大厅原生操作

使用自己的开发端口 4519 和会话 `apppostqa`，以跟踪的旧存档 fixture 加官方作者路线真实重放，构建 84 场主线证明作为测试准备；没有向网页写入伪造的完成标记。这份准备存档不是 84 场本轮原生操作的证明。

1. 先导入旧三关存档，大厅未将旧任务名称或泛泛通关数冒充当前模板的来源证明，显示零类解锁。再导入 84 场真实回放准备存档，大厅显示 24 / 24 类可接取。
2. 准备存档同时保留正在运行的普通委托与远征、当前选择主线。通过原生文件导入后，两项隐藏尝试都追加真实暂停动作，选择仍为主线；预算不变，84 场主线及历史证明保留，生成 ID 没有进入主线 `games`。
3. 大厅只展示当前已到达的一层，后两层显示未知城区。未结束远征阻止覆盖为新远征或新普通委托；此前普通尝试仍可返回。
4. 返回 `typed-schema`、种子 71 的普通委托。工坊显示 0 / 3，亲自选择观察、行动、验收，接通反馈和独立验收并应用。观察实际门状态后，选另一扇门及整数参数 1，执行实际开门，再验收；三次工具请求共花费 5 点（1 + 2 + 2），真实获胜。
5. 胜利后保留一份普通变体证明，显示独立的长期委托结算；主线仍为 84 场、84 份历史记录，没有加入生成 ID，没有借用主线剧情选择或重发主线奖励。构筑／派遣前的两个普通检查点在各自区域显示。
6. 返回种子 77 的远征第一层，实际观察花费 2 点，共用资源由 49 降至 47。通过大厅选择本层重试，资源仍为 47、保留一次已收费尝试，现场重新进入等待构筑状态；工坊显示空法器，没有退款或自动套入答案。

这轮已验证模式往返、隐藏尝试导入暂停、普通配置和真实胜利、证明归档与远征收费重试。**没有在此会话原生走完三层远征，也没有完成新版 PWA 断网冷启动、更新和回滚全流程**；软件三层回放与先前 v0.10 离线验证不能替代这些新版界面检查。该会话和服务器已关闭。

- 在第二关工坊，选第一关真实交付构筑并点“放入工坊草稿”。界面三件法器已选，四项访问 checkbox 全部未选；虽然来源使用 `'*'`，目标草稿仍为零权限。点击前后的 IndexedDB 当前游戏及动作完整 JSON 严格相同，世界、预算和执行记录都没有变化。
- 亲自勾选看归属、修锁和重新封包裹三个目标并应用，才新增一个 `configure` 动作与事件；现场状态、工具请求数和 16 点任务预算仍不变。未授权拆包裹。
- 从第三关返回第二关已有存档，原三件法器、三个玩家签署的权限、六个已提交动作和实际完成状态都保留。已有存档没有被新默认构筑覆盖。
- 通过“重新尝试当前委托”重试第二关，再选它自己曾经的交付构筑，同目标的四项权限仍全部空白；放入草稿前后存档严格相同，历史胜利仍可作为来源。

## 存档、学习证据与公开信息边界

`season-0.11.0` 存档在原容器增加可选 `postSeason`；旧 0.10 的 84 场容器可迁移，但旧版本不能夹带当时不存在的长期进度。普通尝试、远征当前状态、完整动作及历史证明同一次提交，并沿用写入锁。生成关卡胜利不调用主线完成归档，不塞入主线 ID 容器。

普通变体最多保留 48 份胜利证明，同一个实际有限决策分支只保留一份，后续真实未用提示的胜利可加强已有用提示证明；更弱重打不降级较强历史。三个普通检查点与三个主线检查点分开。提示与已打开的评价案例通过真实 `hint` / `mark-seen` 动作保守带入检查点，即使切到别的委托再恢复也不能洗白；恢复已暴露的排队案例不能再宣称初见。远征保留自己的实际费用、层起始预算、完成层和外层历史，禁止普通 `reset` 退款，也不把动态预算的远征记录冒充普通挑战证明。

当前普通尝试、当前远征及最近一次完成远征各保留一份；未结束远征不能被新入口覆盖。长期保留动作的总数上限为 4000（含不同保存数组中的重复记录），整体导入／导出限制为 **16,000,000 字节**。两个已执行容量路径分别如下，不能混为一次测量：

| 容量准备方式 | 紧凑 JSON | 实际导出格式／缩进 JSON |
| --- | ---: | ---: |
| 已有原生 84 场准备文件 + 48 最强变体 + 当前普通／三个普通检查点 + 最近完成／当前远征 | 4,926,856 字节 | 8,061,515 字节 |
| 软件完整重建 84 主线 + 同类长期记录，并保留三个主线检查点 | 3,756,539 字节 | 6,290,148 字节；真实序列化后严格导入通过 |

第一种路径长期部分保留 630 条动作，单独长期紧凑／缩进 JSON 为 877,304 / 1,516,462 字节。两条路径均小于限额；并非承诺任意无限重试都能无上限保留。

成长与能力档案只从核验过的官方作者状态和实际证明派生，保留“见过”“引导完成”“独立迁移”的差别。能力地图接收按原通关顺序保存的历史及尚未完成的官方现场；新种子、重复刷关、客户端 `firstEncounter` 或工厂分支编号不能制造独立迁移。工厂 1 变体只记录见过／练习完成，`freshWins` 恒为 0。旧内核历史保留其来历，不冒称通过新版迁移契约。来源之后两次不同作者主线的真实首胜可触发最多三条复习建议；建议仅打开并聚焦相应大厅卡片，不自动接取或装配，不抬升证据等级。

生成任务使用独立、适用于变体的开场、规则、提示和复盘；保留来源概念与美术，不照搬可能随种子改变的原关参数或顺序。大厅不展示参考路线、未来层事实或初始世界。指挥台与系统／技术复盘只公开真实读到、接回或披露的事实快照及来源：后台 `world-change` 的原始字段、未读总图、未开始宿主消息、伙伴未公开私有输入和隔离评价世界不被转储为玩家答案。沙箱来源与旧快照仍明确标记，已观察值不会被隐蔽现场的更新偷偷替换。定向实际内核／SSR 检查覆盖这些边界；不是对任意新增 UI 的永久保证。
