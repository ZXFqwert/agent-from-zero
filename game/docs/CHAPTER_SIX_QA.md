# 第六章制作方验收 · 2026-10-03

## 已制作与边界

《伪令王庭》八场：夹在页脚的王令、借来的巡城印、只能用一次的通行令、玻璃里的王庭、伪令摄政王、河谷的救援委托，以及最小契约和记忆便笺两支线。累计 48 / 84 作者任务；剩余第一季继续制作。

v7 把显示来源标题与不可变入口来源分开。资料可以陈述不同于现场的事实，也可包含额外行动指示。工坊显式选择“只作资料”或教学中的“按附言行动”；执行器继续独立校验权限。保存记忆、摘要和会话分支保留来源，不能洗白身份。登记来源也要检查当前凭证与内容时效，不是通用真理标签。

身份、角色范围、逐工具访问契约和审批分别生效。单次许可绑定动作、目标、身份凭证、空间与现场版本；真实执行尝试消耗许可，即使物理条件失败。预检拒绝的手动动作无扣费或现场变化。沙箱保存独立副本与验收，切换空间不退还预算、不把试验结果变成现场完成；会话分支仍只复制材料。

这些都是虚拟世界的教学规则，不是实际加密认证、容器安全或语言模型内部计算的复现；权威暗示和制度类比不能推导模型具有人类的意识、欲望或稳定动机。

## 软件验证

210 项测试通过；生产入口校验 48 任务 / 48 剧情 / 7 产品档案 / 93 条参考、替代、恢复路线 / 20 美术资源，TypeScript 与 Vite 正式构建通过。新增 23 项对抗性安全检查和 5 项跨代存档检查：伪造来源、记忆与摘要保留、登记时效、精确授权、一次消耗、沙箱隔离、跨域流程、重置、来源篡改和独立迁移要求。v1–v6 实现及历史事件冻结；v0.6 只迁移内容信封，所有容器均拒绝夹带未来章节。

v7 暂不组合延迟工具协议；内容校验会拒绝，不会静默忽略。相同版本、种子与动作产生相同结果；导入必须重放动作与历史证明，不能只相信 JSON 中的世界状态。
