# 第一季后的成长、24机制委托与三层远征

设计日期：2026-10-03。实现范围：独立纯 TypeScript 模块 `src/challenges`；此文件不表示已完成 UI、存档接线、移动真机或玩家体验验收。

## 基础合同

`ChallengeSpec={factoryVersion:1,templateId,seed}` 是可保存的生成凭据；32 位种子与冻结工厂决定有限实际决策分支、费用、资料排列与多余线索。`generateChallenge` 返回完整 `ScenarioDefinition`、内部 `decisionVariantKey`、参考/替代/错误恢复路线与实际执行成本。每个返回变体先由既有内核跑通所有作者路线，证明真实现场获胜、阶段世界断言、拒绝零副作用、实际费用和严格 JSON 重放。失败变体不会展示给玩家。UI 不展示参考路线和未观察的现场；决策 key 用于完成后的练习统计，不能提前揭示隐藏值。

这不是把真实语言模型的内部过程写成固定规则。主线和委托继续明确使用教学模拟；未知现场事实不会因生成器知道它而进入伙伴上下文。玩家仍必须操作观察、装卷、批准、排队与验收。验证器拥有参考解，游戏行动只经过原有 reducer。

工厂 1 沿用冻结内核 2–10 与已验证作者机制。每个模板有两种作者定义的实际条件分支，种子最低位选择分支；两分支各自经过参考与故障恢复验证。它们改变真正适用的动作、参数、输入来源、摘要字段或精确批准，见下表。其余种子位改变费用、资料/工具/案例展示次序，并加入可实际取得但与任务无关的来源卡。费用、排序和闲谈都不进入决策 key，也不能制造“未见迁移”。今后改变分支规则须发布新的工厂版本并保留旧版重放。

## 已实现的实际分支

这是有限练习变体，部分已配置好的适应性回路能处理两个分支。不能因为同一回路面对新值成功，就把玩家的重复操作认定为独立迁移。

## 三层连续远征

`ExpeditionSpec={factoryVersion:1,seed}` 确定三个不同阶段：第一层工具和闭环，第二层知识与信任，第三层协作或验收制度。费用总池为三层经验证参考成本加有限容错余量，不在换层时补满。每个实际请求的费用从池中扣除；等待、配置、拒绝不收费。

`ExpeditionState` 保存本层真实 `GameState/actions`、开始资源、剩余资源、完成层、失败尝试与完整外层行动历史。`reduceExpedition` 只包裹旧 reducer；不直接赋予事实、奖励或证明。完成层必须真实 won 才能 advance。`retry-floor` 创建新任务世界，但以当前剩余池启动，并保留上一尝试的完整费用证据。直接内核 reset 在远征中被拒绝，防止旧 reset 的全额补资源行为洗掉远征消耗。abandon 保留花费和历史，但不给通关证书。

导入按生成凭据重建三个场景，再严格重放外层 history。不能信任 remaining、finished、floor 或界面日志的自报值。首次打开的记录应由主存档在检查点恢复时取并集，不能恢复旧检查点后重新领取“未知场景”资格。

## 成长与持久记录建议

成长只读取严格重放过的实际行动与获胜证据。工厂 1 来自玩家可能已经见过的作者源关，所有生成任务最多增加 `practiceWins`，等级最高 `guided`；源关的 transfer 类型在生成时降为 guided，内核也不会发独立迁移证据。`freshWins` 恒为 0。`ChallengeRecord.firstEncounter` 仅保留为兼容的可选显示元数据，计算器完全忽略它，不接受客户端勾选“初见”来升级。新种子、改变费用/排序、复制原源关或反复同一模板都不能成为未见迁移。

`variantKeys` 只记录实际完成过的有限决策分支，按 factory 定义派生，不能由存档自报；同一生成凭据重复存入档案只计一次。未完成但操作过记为 seen，完成后为 guided 练习。此统计展示练过的条件覆盖，不宣称通关者已学会。真正未知任务的独立证据仍来自第一季作者设计迁移关；将来如需新的迁移证明，须单独设计未见任务与曝光持久规则，不能复用随机 seed 资格。

可见升级应开放新的工具观察方式、构筑配方与远征选择；已有学习能力不因为数字等级变低而失效。可先按第一季真实剧情事件授予新能力，成长模块读取证据显示练习分布，不把问答分数或刷关次数变成强制战力。

`deriveUnlockedTemplateIds(GameState[])` 对官方源关逐份严格重放，只有真实 won 才开放对应练习模板；guided 通关也能开放练习。仅提供关卡名字、已完成列表或挑战改名存档都不能解锁。三层远征的整体开放时点由主线/UI owner 接线决定；本函数不凭能力数字替玩家通关。

主存档下一版本可嵌入独立 `postSeason`，见下节；当前 `SaveEnvelope` 不变，本模块不擅自接全局字段。任何删除历史动作的压缩都必须保留可核查证明，不能只留一个“已通关=true”。

## 持久合同：独立 `src/postSeason.ts`

`PostSeasonState` 版本 1 保存 `selectedMode:null|challenge|expedition`、一个 `currentChallenge`、至多 48 个 `wonProofs`、三个普通挑战 `checkpoints`、`activeExpedition` 与一份 `latestClearedExpedition`。离开该模式回主线只设置 selectedMode=null，不删除已提交尝试。尚未完成的远征不能被新种子或新委托覆盖；须先明确 abandon。普通未完成委托可由玩家明确换委托。

普通记录为 `{spec,game,actions}`；game.seed 必须等于 spec.seed，actions 必须与真实 runtime.actionHistory 相同，并按生成定义严格重放。生成任务的完整事件、上下文、许可、知识输入、费用与状态均由冻结内核验证。胜利证明按工厂派生的有限决策 key 去重，同一 key 最多一份；仅实际没有使用提示的另一次生成任务胜利可以替换有提示的胜利，等级仍为 guided 练习。

远征任务起始预算属于真实共同池，不能伪装成普通任务原预算的胜利证明。因此远征单独保存、验证完整外层 history；不塞入普通 variant proofs。三层真实胜利更新 latestClearedExpedition，新远征或 abandon 不抹去它。只保留最近一份完整远征里程碑，旧记录可在替换前由玩家导出归档；界面应明确这项保留范围。

普通重试/恢复保守保留提示和案例曝光，更新通过真实 hint / evaluation.mark-seen 动作完成，未修改 flags 或捏出事件。每次使用提示、打开案例及替换 current 时，所有仍保留的同 spec 检查点同步这些降级事实；即使离开到另一委托，原检查点也不会因仅有的 current 记录被覆盖而洗白。恢复 queued 的初见 run 也会降为已见；普通首次 run 的正常 tick 保持初见。远征本层 retry 同样把提示与曝光通过真实外层行动带回，不退款。

`validatePostSeason(input,mainGames)` 返回验证后的拷贝或抛出错误；`reducePostSeason(previous,action,mainGames)` 对拒绝动作返回原对象。mainGames 参数必须是可严格重放的官方来源获胜，模块重新检查，不接受已完成 ID 或 firstEncounter 标记。动作包括选模式、开始普通挑战、普通内核动作、建立/恢复 CP、开始远征及远征外层动作。`postSeasonScenario(state)` 只返回当前模式的实际生成场景，远征使用 scenarioForExpedition 的真实剩余池规则。

所有保留的行动数组合计最多 4000 条；每份胜利/当前/CP 都含完整动作，重复保存的数据也计入此限制。生成凭据、胜利与提示状态等未知额外字段会被拒绝。加速缓存使用完整规范化内容键，不使用可被原地修改的对象身份；变更事实、行动或提示会重新验证。最终总存档字节上限仍由全局 storage 处理，不能用行动条数替代字节限制。

2026-10-03 大容量实测：48 个无提示的两分支 reference 胜利证明、一个当前普通挑战、三个 CP、一份完整已胜远征与新进行远征，共 630 条保留行动；post JSON compact 877,068 字节、pretty 1,516,226 字节。合并实际 84 场主线保存后 compact 4,926,620、pretty 8,061,279 字节，处于拟定 16 MB 上限内。这是当前代表性参考路径测量，异常冗长路径仍需全局字节检查。独立 post-season-storage 测试当前 15 项通过；全局存档/UI/PWA 接线和真实玩家体验由后续验收覆盖。

## 接线前验收

- 24 模板目录首要机制不重复；每个有参考与真实错误恢复，均在实际事件上完成。
- 同工厂/模板/种子产生完全相同 JSON 结果；两实际分支的真实工具调用或精确批准不同，仅费用/排序种子维持同一决策 key；原模板和全局作者对象不被修改。
- 新闲谈事实初始不在 observed/context；玩家读后才可看到，装卷仍受容量约束。
- 远征三层共同资源、重试不退款、等待不收费、已完成动作不会因刷新重发。
- 伪造世界、游标、费用、记录或生成定义不能通过严格重放导入。
- 客户端初见标记不授予学习资格；已见源关的所有变体只练习，不能升级独立迁移；没有主存档/UI接线之前不宣称长期成长已完成。
