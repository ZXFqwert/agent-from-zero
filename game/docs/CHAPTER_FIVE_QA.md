# 第五章制作方验收 · 2026-10-03

## 已制作与适用边界

新增八场：隔夜的口令、蒙尘的捷径、中断的抄写台、留下修泵的方法、重写者的旧律、被水围住的书房，以及分叉的信使、一次成功的传说两支线。累计 40 / 84 作者任务。此章是明确规则的教学模拟，不调用真实模型，也不表示模型拥有意识或稳定信念。

v6 使用与当前卷轴分开的持久档案，实际读到的原资料才能保存或修订，旧版留作停用记录。检索只是复制保存时快照，必须装卷；修订不更新已经携带的旧副本。档案和已学流程跨本冒险的会话、刷新、委托重置保留；跨委托共享工坊档案尚未开放。

会话支持空白、复制分支、恢复（最多八段）。会话切换不复制世界、不退还预算、不赋予新权限；交班要求当前确为新空白会话，续写与审计要求恢复初始会话。会话来源从实际动作历史推导，不凭标签认身份。分支不是沙箱。

流程采用固定配方，界面明确显示适用条件与逐步调用。玩家先按次序成功执行真实请求，才能保存；保存本身不执行工具、不改权重。启动流程建立队列，每次“伙伴决定一步”仍执行一笔有成本、权限和回执的工具请求；失败停止、暂停保留游标，手动改指令取消旧队列。交付必须有测试台重置之后的新执行证据。

v1–v5 行为与事件字符串冻结，v0.5 存档仅迁移内容信封。v6 暂不组合延迟工具协议，内容入口会拒绝。复杂组合在后续内核实现，不能静默忽略字段。
