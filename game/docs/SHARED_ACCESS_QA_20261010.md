## 实现与兼容

- 前端入口经服务端验证口令，只保存 opaque Bearer 凭证和独立的本机解锁标记，不保存口令，也不在前端资源写入口令或模型密钥。根域验证后转到 `/play/`，再挂载游戏和打开 IndexedDB。
- 错误口令、响应异常、断网和存储写入失败都留在表单并显示原因；不重建游戏存档。已解锁主线不受实验凭证过期影响；首次解锁需要网络，已下载章节可离线。
- Lab 直接复用入口凭证；旧有效实验 token、待确认操作和只读记录兼容。新登录不继承旧操作归属。各浏览器是独立会话，没有公共账号或云存档。
- `/api/lab/access` 只接受严格 JSON；口令精确匹配，常量时间比较摘要。新会话使用稳定的共享额度身份，重新登录、换口令和重启不重置额度。旧邀请路径仅作旧凭证兼容，不再展示邀请领取／兑换界面。
- 新口令入口的真实实验每日共享10场、全局并发1、最多8轮／120秒／每轮512 token；主线不限次数。此轮没有新增真实 Provider 请求。
- SQLite schema 3 只新增可空的 `invites.quota_id` 与索引；保留旧会话、历史和请求幂等记录。旧执行代码不能安全实施共享额度，因此失败回退必须禁用旧代码的模型创建能力，不能只凭 SQL 能读取就认定兼容。
- 发布元数据新增 `accessMode: shared-passphrase-v1`，仍保持原模拟摘要和存档版本。根 HTML 与 `/play/index.html` 完全相同；安全发布器保留归档。启用共享入口后，普通回滚拒绝退回缺少该入口的旧前端。
