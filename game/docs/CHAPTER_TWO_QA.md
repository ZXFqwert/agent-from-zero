## 概念来源与教学简化

核查日期 2026-10-03。[OpenAI 官方 Function calling 文档](https://developers.openai.com/api/docs/guides/function-calling) 中 Chat Completions 示例把工具结果的 tool_call_id 对应到原调用 ID，也由应用执行工具。游戏的编号配对来自这一外部协议层的理解；延迟风管和参数选择是教学抽象，规则策略不复现模型内部计算。

[RFC 9110 §9.2.2](https://www.rfc-editor.org/rfc/rfc9110.html#name-idempotent-methods) 区分重复请求的预期服务端效果和逐次日志等其他效果，并说明回执失败后的重试问题。游戏据此设计了需要执行器保存、核对的业务键；没有把它说成通用 HTTP 请求或模型自带的保证，也没有承诺原回执等于最新现场。
