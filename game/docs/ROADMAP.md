## 产品目标

《回声工坊：失序之城》：零编程基础的单人手机网页游戏，以奇幻冒险、伙伴构筑和机制战斗让玩家真正理解 Agent。模型的语言输出与世界执行分开；故事先行，技术视图渐进开放。平台为 `agent.li33.art`，PWA，下载章节可离线，IndexedDB 本地存档。账号、多人、排行榜与付费不在第一季。

第一季目标 12–20 小时，必须通过实际试玩校准。八章，每章四主线、一首领、一独立迁移、两支线（64）；序章三关、终章三关、七组现实蓝图各两次试炼（14），合计 84 个作者设计任务。一个主要伙伴、两个协作伙伴、六名核心 NPC、八个章节首领。长期玩法为 24 个可解性验证后的任务模板、三层远征与混合构筑。

八章顺序：熄火之港（闭环）、失灵法器街（协议）、无尽钟楼（规划与预算）、遗忘回廊（上下文）、旧日档案馆（记忆技能）、伪令王庭（信任权限）、七匠之桥（协作）、镜面议会（评测与制度）。

七组现实参考：Codex、Claude Code、OpenClaw、Hermes Agent、OpenCode、Pi、DeepSeek Harness。比较系统取舍，不设品牌战力榜。版本、核查日期、官方来源和教学简化分别记录。社会心理学映射到权威暗示、确认偏误、群体盲从、委托与激励错位，不据此断言语言模型有人的意识和稳定动机。

## 已实施的技术方向

TypeScript + React + Phaser + Vite；纯函数模拟内核与决策适配器分离，内容配置不执行任意代码，动画不决定胜负。主线与长期委托使用明确标识的规则模拟；真实模型仅在独立实验区使用受限虚拟工具。

实验区为 FastAPI + SQLite、独立服务环境变量、共享工坊口令、独立会话、额度、幂等、超时和取消。本轮默认全站每日共10次、全站并发1、8轮、120秒、512输出token；重新登录不扩充共享额度，主线不限次数。口令只由服务器验证，网页保存 opaque 凭证与独立离线解锁标记，不保存口令；旧有效 token 和未确认操作优先恢复，新会话不继承旧操作归属，只读记录保留。不读取根学习项目 `.env`，不接触实际文件或命令。`deepseek-flash` 已连接；四场服务端实验22轮与一场公开网页对照8轮均已记录。第五场两组各4轮、各7次成功工具、零拒绝，均预算耗尽且未验收，总体 incomplete；不据此推断构筑强弱，见 [真实模型验收](../server/deploy/REAL_MODEL_QA.md)。第二模型尚未获用户决定，仍关闭。

v0.11 的462项软件测试、TSC、174条作者路线及构建通过，40项公开资源大小/SHA一致。原生浏览器已走完48场有限变体、三层远征、重试不返预算与断网冷恢复。能力旅历按每个概念的真实记录派生，不给整章统一“已掌握”；延迟回访只推荐已解锁模板，既有源机制、新编号和种子不冒充陌生迁移。交付构筑从可验证记录起草，只复用结构策略，权限重新签订，不复制材料或主世界事实，也不等同于 Agent 持久记忆。长期验证见 [POST_SEASON_V011_QA.md](POST_SEASON_V011_QA.md)。

v0.12在冻结关卡之外增加稳定`conceptId`映射：20个核心概念，每个具有引导、无提示实操、陌生迁移、间隔重遇四阶段。旧84作者记录对应58/80阶段、19个核心概念独立迁移；不根据旧存档的任务排列推断过去的重遇。独立IndexedDB从新版实际作者胜利开始保存完成顺序，最多96条；复制动作轨迹或只改种子不产生新阶段。重遇需要另两种实际主线完成和新的无提示操作。幂等的陌生作者迁移仍是明确缺口，不用其他工具协议任务顶替。

个人毕业项目有8个逐步实现环节、34项本机检查及真实练习文件。最终个人阶段重新运行前七步27项检查，以当前代码完成玩家定义的任务、核验成果并在成果被破坏后拒绝验收。默认使用本机脚本模型，真实模型需显式`--live`；项目不读取根Python配置。工坊报告要求完整清单、个人委托指纹及代码指纹；修改委托后个人通过记录失效。本机报告可编辑，各步历史报告也可能来自不同代码版本，均不冒充不可伪造的掌握证明。根Python S5与用户自己写代码的学习约定保持独立。

三场「无名蓝图试炼」先隐藏品牌，让玩家根据陌生委托配置信息来源、上下文、权限、会话、队列、交接及副作用控制；配置会改变虚拟执行结果。三场实际构筑成功后才揭示七类产品的设计参考。模拟胜利不等于真实产品测评，也不能代替玩家对选择与代价的解释。

v0.13在独立`courier-v1`模块提供两份固定作者委托：医院一箱与夜市两箱。实际副作用、回执丢失、宿主重启、账本恢复、新调用同业务键重试、参数冲突和现场验收逐步发生。安全封缄可以避开故障并真实交付；迁移证据要求对应恢复操作。提示曝光跨重试与备份保留，合法历史证明不因后来提示撤回；只向学习链增加幂等迁移，不发主线奖励、不改旧主线。浏览器原生导出的旧主线仅时间变化，公开第2章下载后断网新交付与冷恢复通过。旧版回退仅保留新数据库、不提供玩法，兼容边界见回滚文档。
