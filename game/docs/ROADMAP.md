# 经用户确认的制作路线

确认日期：2026-10-02。完整方案由用户直接提供并要求实施；本文件只记录实施边界与接续点。

## 产品目标

《回声工坊：失序之城》：零编程基础的单人手机网页游戏，以奇幻冒险、伙伴构筑和机制战斗让玩家真正理解 Agent。模型的语言输出与世界执行分开；故事先行，技术视图渐进开放。平台为 `agent.li33.art`，PWA，下载章节可离线，IndexedDB 本地存档。账号、多人、排行榜与付费不在第一季。

第一季目标 12–20 小时，必须通过实际试玩校准。八章，每章四主线、一首领、一独立迁移、两支线（64）；序章三关、终章三关、七组现实蓝图各两次试炼（14），合计 84 个作者设计任务。一个主要伙伴、两个协作伙伴、六名核心 NPC、八个章节首领。长期玩法为 24 个可解性验证后的任务模板、三层远征与混合构筑。

八章顺序：熄火之港（闭环）、失灵法器街（协议）、无尽钟楼（规划与预算）、遗忘回廊（上下文）、旧日档案馆（记忆技能）、伪令王庭（信任权限）、七匠之桥（协作）、镜面议会（评测与制度）。

七组现实参考：Codex、Claude Code、OpenClaw、Hermes Agent、OpenCode、Pi、DeepSeek Harness。比较系统取舍，不设品牌战力榜。版本、核查日期、官方来源和教学简化分别记录。社会心理学映射到权威暗示、确认偏误、群体盲从、委托与激励错位，不据此断言语言模型有人的意识和稳定动机。

## 已实施的技术方向

TypeScript + React + Phaser + Vite；纯函数模拟内核与决策适配器分离，内容配置不执行任意代码，动画不决定胜负。当前策略为明确标识的规则模拟，未来真实模型只在独立实验区使用受限虚拟工具。

实验区为 FastAPI + SQLite、独立服务环境变量、一次性邀请码、额度、幂等、超时和取消。默认每邀请每日 10 次、全站并发 1、8 轮、120 秒、512 输出 token；不读取根学习项目 `.env`，不接触实际文件或命令。真实模型连接与上线测试仍待对应阶段。
