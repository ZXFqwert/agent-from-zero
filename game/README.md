## 本地运行

Node.js 22.12+（本次 Node 24.15）。依赖精确锁定，无脚手架匿名日志。

```powershell
cd game
npm ci
npm run dev
```

地址 `http://127.0.0.1:4174/play/`。检查与正式构建：

```powershell
npm test
npm run validate:content
npm run build
npm run preview
```

离线功能只在正式构建启用。`build` 自动生成资源版本及 `offline-manifest.json`，首次打开不会强制下载离线包。外部官方资料与真实 AI 实验需要网络。

普通本地构建默认关闭共享入口与真实实验，便于开发。已配置独立后端时，公开构建只打开界面开关；工坊口令只在服务器验证，口令与模型密钥不进入 Vite 变量或浏览器存储：

```powershell
$env:VITE_ACCESS_ENABLED = 'true'
$env:VITE_LAB_ENABLED = 'true'
npm run build
Remove-Item Env:VITE_ACCESS_ENABLED
Remove-Item Env:VITE_LAB_ENABLED
```

## 发布边界

游戏资源发布至 `/play/`，旧版保留在 `/archive/v1/`。本轮部署已让根 `/` 返回游戏口令入口；验证成功或已有本机解锁后，先跳转 `/play/` 再挂载游戏，维持既有 PWA、离线 scope 和同源存档。根入口切换已在公开Chrome中确认，用户最新要求已覆盖此前“先保留旧站直到真机验收”的顺序。发布仍原子切换 `current`，不修改其他 Nginx 站点或 Python 练习；哈希资源跨 release 保留供尚未关闭的客户端使用。

现有 Nginx 的 `Cache-Control: no-cache` 对 Service Worker 和 manifest 同样适用。Service Worker 缓存名含构建哈希，不在游戏中自动 `skipWaiting`，也不删除旧缓存。四份生产发布工具位于 `/opt/agent-game-static-deploy/`，同用排他锁、完整资源与存档兼容检查，失败恢复切换前的准确链接。客户端在安全检查点应用检测到的对应 Worker；包含长期记录的 0.11 不能回退到不兼容的 0.10。真实兼容回滚已另行演练，详见 [ROLLBACK.md](deploy/ROLLBACK.md)。

v1–v10 作者内核、长期 `factoryVersion: 1` 与签收站 `courier-v1` 规则已发布冻结。改变模拟行为、内容或存档规则须制定新版本及实际迁移，不能仅沿用旧规则编号；当前回滚工具仅接受主线模拟摘要完全相同的兼容版本，独立模块可读性须另外核查，详见回滚文档。

生产部署与验收实况见 `docs/DELIVERY.md`。图片提示词、来源、尺寸与格式转换记录见 `docs/ART.md`。真实设备触控、安装、音效以及乐趣和学习效果需要用户试玩，浏览器自动化不能替代。
