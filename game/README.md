# 回声工坊：失序之城

手机竖屏 Agent 学习冒险。独立于根目录 Python 教学项目，旧网站源码仍在 `../website/`。

## 当前交付范围

当前 v0.11 已在 [agent.li33.art/play/](https://agent.li33.art/play/) 发布，可继续玩完整第一季内容与长期模式。84 个作者任务保持：八章 64 场、序终章各 3 场，以及七款现实蓝图各 2 场机制试炼；28 项原创场景角色资源。序章直接从拉开工坊窗帘开始，终章要求诊断陌生系统、配置协作，再检验城市整体结果。八章依次覆盖闭环、工具协议、规划与停止、上下文、记忆技能、信任权限、伙伴协作和独立评测，174 条参考、替代及错误恢复路线由实际内核运行。

长期模式已有24类机制不同的委托模板、各两种有限决策分支和三层共享预算远征。玩家完成对应来源任务后才能接取；新编号、费用或排列变化不会成为新的独立迁移证明。制作方实际走完48场模板变体、三层远征、重试费用保留与断网冷恢复；能力旅历、延迟重遇建议和显式构筑复用已接入。当前公开 release 为 `20261003-220005`、构建 `211068a2ebb828909d8864b7`，462项软件测试、TSC、作者路线校验及构建通过，40项公开资源逐项大小/SHA一致。软件与制作方试玩不证明真机体验、玩家乐趣、实际学习效果或12–20小时体验时长，最终上线验收仍待完成。

- React 负责中文剧情、工坊、可访问操作和记录；Phaser 负责原创场景、伙伴、灯光、开门与首领反馈。
- 纯 TypeScript 内核模拟工具请求、实际执行、上下文回执、访问权限、预算与验收。只有世界事实与独立证据相符才会获胜。
- 自动与逐步指挥，点选能力/目标/成本后执行；三层事件复盘，按真实动作回放。
- v2 区分整项任务能量与单次派遣预算，增加容量、操作成本、目标排序、事件与证据撤销。旧三关继续冻结 v1 行为，旧存档可迁移。
- v3 将参数刻度、单次调用编号与业务凭证分开。成功业务保存执行凭证，匹配重试只重送原回执；领取回执不代替新鲜验收。
- IndexedDB 每次动作提交后更新 UI；三个恢复检查点、JSON 导入导出、历史通关去重、提示使用证据保留。
- 九个独立离线包，含序章、八章、终章及现实试炼需要的场景。资源逐项哈希核验；更新只在安全检查点显式应用。
- 七款产品两场试炼分别体验其设计和取舍。模型、岗位、工作区、入口路由、队列、扩展信任与执行边界分别生效；资料页附官方出处、源码版本、核查日期和教学简化。不设品牌战力榜。
- 复盘可分三步导出 Python 消息、工具及有限循环骨架；只使用已观察信息与当前可用工具，实际工具实现由学习者补充，默认不发模型请求。
- 长期委托和三层远征保存完整实际行动；远征同用有限资源，重试不退款、不能用普通关卡重置补晶石。生成记录独立于84场主线，不改主线剧情或重复发奖励。
- 能力旅历逐概念展示见过、引导实操和独立迁移及实际来源；旧版情境完成不冒充新版迁移。延迟重遇只建议已解锁的少量模板，不凭种子初见、时间或品牌打分。
- 已交付构筑可显式放入工坊草稿，来源须为验证过的作者、普通委托或完整远征记录。仅复用法器和策略，新权限为空，目标顺序、参数、卷轴、身份、审批和模块不随之复制；由玩家重新配置并应用，不宣称伙伴获得持久记忆。
- `server/` 独立实验后端已连接 `deepseek-flash`，VPS Python 3.10.12 的40项假 Provider测试与真实模型分别验收。四场服务端实验22轮加一场公开网页对照8轮，共五场30轮；保留真正验收、预算耗尽和取消。网页第五场两组各4轮、各7次成功工具、零拒绝，均用尽预算且未验收，总体 incomplete；390宽浏览器布局无溢出、没有页面错误，不等于手机真机通过。单伙伴、同模型不同反馈、单伙伴与协作可用；第二模型未配置，对应对照继续关闭。实际记录见 [REAL_MODEL_QA.md](server/deploy/REAL_MODEL_QA.md)，早期假服务界面验证见 [LAB_CLIENT_QA.md](docs/LAB_CLIENT_QA.md)。默认每日10场、全局1场、每场8轮/120秒、每轮512输出token，工具只作用于虚拟世界。

## 本地运行

Node.js 22.12+（本次 Node 24.15）。依赖精确锁定，无脚手架匿名日志。

```powershell
cd game
npm ci
npm run dev
```

地址 `http://127.0.0.1:4174/play/`。检查与正式构建：

```powershell
npm test
npm run validate:content
npm run build
npm run preview
```

离线功能只在正式构建启用。`build` 自动生成资源版本及 `offline-manifest.json`，首次打开不会强制下载离线包。外部官方资料与真实 AI 实验需要网络。

普通本地构建默认关闭真实实验。已配置独立后端时，公开构建只打开界面开关；密钥不进入 Vite 变量或浏览器：

```powershell
$env:VITE_LAB_ENABLED = 'true'
npm run build
Remove-Item Env:VITE_LAB_ENABLED
```

## 结构

```text
src/engine/          纯函数规则、教学策略、事件和导入校验
src/content/         八十四个任务、剧情、依赖图与来源可查的产品档案
src/challenges/      冻结模板与有限变体、来源成长、共享预算远征
src/postSeason.ts    长期模式的实际行动、检查点与完整父容器校验
src/learningAtlas.ts 按概念派生能力旅历与有限回访建议
src/buildReuse.ts    真实交付来源与空权限构筑草稿
src/components/      工坊、复盘、大厅、能力旅历、实验台和对话框
src/Scene.tsx        React → Phaser 单向表现桥接
src/storage.ts       IndexedDB、动作回放校验、原子恢复
src/offline.ts       显式章节下载与安全更新
public/art/          优化后的原创游戏 WebP
art-source/          原始美术文件（不发布到网站）
public/sw.js         仅拦截 /play/ 的 Service Worker
scripts/             内容/参考路线校验、离线清单生成
server/              独立 FastAPI + SQLite 实验后端
tests/               内核与存档证据测试
deploy/              发布与回滚脚本
```

主线内核不调用模型，不宣称复现模型内部计算。作者任务与长期有限变体分别记录；重复源机制只计练习。七款产品的游戏类比不暗示模型具有人的意识或稳定动机。内容规范见 [CONTENT_AUTHORING.md](docs/CONTENT_AUTHORING.md)，第一至八章验证见 [CHAPTER_EIGHT_QA.md](docs/CHAPTER_EIGHT_QA.md)，序终章及现实试炼的历史验收见 [SEASON_V010_QA.md](docs/SEASON_V010_QA.md)，当前长期模式验收见 [POST_SEASON_V011_QA.md](docs/POST_SEASON_V011_QA.md)。发布版本以 [DELIVERY.md](docs/DELIVERY.md) 的最后一条记录为准。

## 发布边界

只打包 `dist/` 至 `/play/`。`deploy/release.sh` 将现站复制到新 release，并在 `/archive/v1/` 保留旧版；根入口暂时保持旧网站。原子切换 `current`，不修改其他 Nginx 站点、Python 练习或真实模型配置。哈希资源跨 release 保留供尚未关闭的客户端使用。

现有 Nginx 的 `Cache-Control: no-cache` 对 Service Worker 和 manifest 同样适用。Service Worker 缓存名含构建哈希，不在游戏中自动 `skipWaiting`，也不删除旧缓存。四份生产发布工具位于 `/opt/agent-game-static-deploy/`，同用排他锁、完整资源与存档兼容检查，失败恢复切换前的准确链接。客户端在安全检查点应用检测到的对应 Worker；包含长期记录的 0.11 不能回退到不兼容的 0.10。真实兼容回滚已另行演练，详见 [ROLLBACK.md](deploy/ROLLBACK.md)。

v1–v10 作者内核与长期 `factoryVersion: 1` 规则已发布冻结。改变模拟行为、内容或存档规则须制定新版本及实际迁移，不能仅沿用旧工厂编号；当前回滚工具仅接受模拟摘要完全相同的兼容界面版本。

生产部署与验收实况见 `docs/DELIVERY.md`。图片提示词、来源、尺寸与格式转换记录见 `docs/ART.md`。真实设备触控、安装、音效以及乐趣和学习效果需要用户试玩，浏览器自动化不能替代。

第七章实际界面、断网队列恢复与审查结果见 [CHAPTER_SEVEN_QA.md](docs/CHAPTER_SEVEN_QA.md)。第八章实际试玩见 [CHAPTER_EIGHT_QA.md](docs/CHAPTER_EIGHT_QA.md)；未制作部分不计入当前任务数。
